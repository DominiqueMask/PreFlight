PreFlight ✈️

PreFlight is a study companion for student pilots preparing for their Private Pilot License (PPL). It brings together reference material, flashcards, and practice questions in one place to help you study anywhere.
Features

Reference Material — Quick-access notes covering key PPL knowledge areas
Flashcards — Review core concepts and terminology at your own pace
Practice Questions — Quiz yourself to check understanding and track readiness for the written exam


Getting Started
PreFlight runs entirely in the browser — no installation required.
Visit dominiquemask.github.io/PreFlight
Start studying — no sign-up needed


Install as an app
PreFlight can also be installed like a native app on desktop or mobile:


Desktop (Chrome/Edge): Click the install icon in the address bar
Android: Tap "Add to Home Screen" when prompted, or via the browser menu
iOS (Safari): Tap the Share icon → "Add to Home Screen"
